Common Terraform Meta-Arguments
1️. count
Creates multiple instances of a resource.
resource "aws_instance" "web" {
  count = 2
  ami   = "ami-123"
}
Creates 2 EC2 instances.

2. for_each
Creates multiple resources using a map or set.
resource "aws_s3_bucket" "bucket" {
  for_each = toset(["dev", "qa", "prod"])
  bucket   = "my-${each.key}"
}
Better than count when working with named resources.

3. depends_on
Defines explicit dependency.
depends_on = [aws_vpc.main]
Used when implicit dependency is not enough.

4.lifecycle
Controls creation/destruction behavior.
lifecycle {
  prevent_destroy = true
}

5. provider
Specifies which provider to use (multi-region setup).
provider = aws.us_east

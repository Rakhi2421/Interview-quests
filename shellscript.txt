File operators(tests)

-d File - True if file is a directory
-e File - True if file exists
-f File - True if file exists and is a regular file.
-r File - True if file is readable by you.
-s File - True if file exists and is not empty.
-w File - True if file is writable by you.
-x File - True if file is executable by you.

String Operators (tests)

-z STRING - True if string is empty.
-n STRING - True if string is not empty.
STRING1=STRING2
    True if the strings are equal.
STRING1!=STRING2
    True if the strings are not equal.
	
Arithmetic Operators (tests)

arg1-eq arg2 -> True if arg1 is equal to arg2.
arg1-ne arg2 -> True if arg1 is not equal to arg2.
-lt -> less than
-le -> less than or equal to
-gt -> greater than
-ge -> greater than or equal to.

Exit Status and Return Codes

- Every command returns an exit status
- Range from 0 to 255
- 0 = success
- Other than 0 = error condition
- Use for error checking

Checking the exit status

- $? contains the return code of the previously executed command.

ls /not/here
echo "$?"

example:

HOST="google.com"
ping -c 1 ${HOST}

if [ "$?" -eq "0" ]
then
 echo "$HOST reachable"
else
 echo "$HOST Unreachable"
fi

(or)

HOST="google.com"
ping -c 1 ${HOST}
RETURN_CODE=$?

if [ "$RETURN_CODE" -eq "0" ]
then
 echo "$HOST reachable"
else
 echo "$HOST Unreachable"
fi 

--------------------------------------
&& and ||

&& = AND - it will execte if exit status of previous command is 0, means previous command ran successful. 
mkdir /tmp/bak && cp test.txt /tmp/bak/

|| = OR  - it will execte if exit status of previous command is not equal to 0
cp test.txt /tmp/bak/ || cp test.txt /tmp

- Seperate commands with a semicolon to ensure they all get executed.

Wildcards:

- A character or string used for pattern matching.
- Globbing expands the wildcard pattern into a list of files and/or directories.
- Wildcards can be used with most commands
  - ls
  - rm
  - cp
Wild cards are *, ? , [] , [!] , 

* - matches zero or more characters.
    - *.txt
	- a*
	- a*.txt
? - matches exactly one character.
    - ?.txt
	- a?
	- a?.txt
[] - A character class.
     - Matches any of the characters include between the brackets. Matches exactly one character.
	   - [aeiou]
	   - ca[nt]* 
	      - acceptable words are can, cat. candy,catch
[!] - Matches any of the characters NOT included between the brackets. Matches exactly one character
      - [!aeiou]*
	    - baseball
		- cricket
Use two characters seperated by a hyphen to create a range in a character class.
- [a-g]*    - Matches all files that start with a,b,c,d,e,f or g.
- [3-6]*     - Matches all files that start with 3,4,5,6.

Named Character classes

- [[:alpha:]] 
- [[:alnum:]]
- [[:digit:]]
- [[:lower:]]
- [[:space:]]
- [[:upper:]]

- \- escape character. Use if you want to match a wildcard character.
   - Match all files that end with a question mark:
    - *\?
	   -done?

Sed = Stream editor
A stream is a data that travels from:
- One process to another through a pipe
- one file to another as a redirect
- One device to another.
Sed performs text transformations on streams.
Examples:
 - Substitute some text for other text
 - Remove lines
 - Append text after given lines.
 - Insert text before certain lines.
Sed is used programmatically, not interactively.

type -a sed  --> to see where it is running or exact path: /usr/bin/sed

sed 's/assistant/manager' manager.txt 
Here s means substitute
/ - delimeter
assistant is going to be replaced with manager in manager.txt 

sed 's/ASSISTANT/manager/' manager.txt
sed is case sensitive so no changes will occur, unless there is a word with capitals in that file.

sed 's/search-pattern/replacement-string/flags'

to ignore case sensitive use flags after the things, we can use i or I both works same
sed 's/ASSISTANT/manager/i' manager.txt
sed 's/ASSISTANT/manager/i' manager.txt

sed 's/assistant/manager/' manager.txt
This command replaces only the first assistant word in a line so we use flag g to replace all words.

sed 's/assistant/manager/g' manager.txt
sed 's/assistant/manager/2' manager.txt -> to replace a second word of all lines.

sed -i.bak 's/assistant/manager/' manager.txt then changes will be applied and saved as a file manager.txt.bkp

to change /home/jason to /export/users/jasonc

echo '/home/jason' | sed 's/\/home\/jason/\/export\/users\/jasonc/'
echo '/home/jason' | sed 's#/home/jason#/export/users/jasonc#'
echo '/home/jason' | sed 's:/home/jason:/export/users/jasonc:'

sed '/This/d' manager.txt   --> deletes a lines contains this
sed '/^#/d' manager.txt   --> deletes a lines contains #
sed '/^$/d' manager.txt   --> deletes an empty lines between lines
sed '/^$/d ; /^#/d' manager.txt  --> deletes both empty and # lines
sed '/^$/d ; /^#/d ; s/assistant/manager/' manager.txt  -->performs all actions
sed  -e '/^$/d' -e '/^#/d' -e 's/assistant/manager/' manager.txt  -->performs all actions

Script file File

echo '/^#/d' > script.sed
echo '/^$/d' >> script.sed
echo 's/apache/httpd' >> script.sed

sed -f script.sed manager.txt  --> performs all actions mention in the script file

Addressing
sed '2 s/apache/httpd/' config
2nd line will be changed
sed '/Group/ s/apache/httpd/' config
line start with group content will be changed
